Step 04 of 08 · Once

What you install

Three packages and a browser extension. A paid Claude account. No code.

ctc-chapter-setupNine questions, then your settings file and plan.Skill
ctc-newsletterFinds sources, collects events and reader submissions, builds the issue.Plugin · 5 skills
ctc-partner-mapResearches your city, says who to approach, drafts the emails.Plugin · 3 skills
Claude for ChromeLuma, Eventbrite and the submission form need a real browser.Extension
A skill does one job. A plugin is several skills installed together. Claude for Chrome is required for the weekly harvest. Download all three zips first; the steps below upload them.

  1. Turn on code execution

    Open claude.ai/settings/capabilities. Make sure Cloud code execution and file creation is on. Skills need it.

  2. Upload the skill

    Open claude.ai/customize/skills. Add, then Upload skill, then choose the ctc-chapter-setup zip you downloaded.

  3. Upload the two plugins

    Open claude.ai/customize/plugins. Add, then Upload plugin. Once for ctc-newsletter, once for ctc-partner-map. A plugin brings its skills with it.

  4. Install Claude for Chrome

    Open claude.ai/chrome, then Add to Chrome. Sign in with the same account.

  5. Create a project

    Open claude.ai/projects, then New project. Name it Climate Tech [your city]. Everything from here on happens inside it.

  6. Check it worked

    Verify install
    Which Climate Tech Cities skills do you have available?
    Claude should name ctc-chapter-setup and the skills in both plugins. If not: check step 1, upload again, and start a fresh conversation. Skills do not appear mid-conversation.
